# 公开认证与深链（F04/F11）

公开分享、邀请、嵌入页、报价确认和状态页无需等待私有认证。公开API不携带私有Bearer，公开会话401不会清除私有登录。私有页登录回跳保留path/query/hash，只接受本站路径并排除登录循环。认证作用域切换忽略迟到响应。

收件箱消费通知的c参数，选择会话同步URL、支持前进后退并保持原有异步隔离；无权限/不存在与网络失败明确提示。助手消费路由预填但不自动创建任务，已有未确认提交优先恢复。既有逾期订单通知的/crm?tab=orders转到订单标签，CRM扩展页标签保持URL状态。

失败断言：3项深链/预填、公开认证原4项；新增登录返回与订单通知回归。修复后全前端40 passed，lint无错误、TypeScript/build通过，仍有既有Hook及chunk大小警告。登录测试曾因AntD中文按钮自动空格定位失败，已改为匹配可访问名称。无数据库迁移；前端整体回退会恢复公开页阻塞及深链失效。

命令：在frontend运行 npm test、npm run lint、npm run build。后端权限与租户检查保留原接口边界，前端深链不授予额外权限。
